## 🌟 Overview

The **CinemaAI 3D Presentation Website** is a cinematic, interactive, slide-based web application built specifically for academic viva and university evaluation defense.

Unlike static PowerPoint slides, this website provides a live, interactive 3D WebGL environment (Three.js neural core, orbiting data rings, particle fields) running directly in the browser at `http://localhost:3000`.

## 🚀 Quick Start Guide (Windows)

### 1. Requirements
- Node.js (v18.0 or higher recommended)
- Modern Web Browser (Google Chrome, Microsoft Edge, Brave, etc.)

### 2. Run the Application
Open PowerShell or Command Prompt in this folder (`cinemaai-presentation-3d`):

```powershell
# 1. Install dependencies (if not already installed)
npm install

# 2. Start the local presentation server on port 3000
npm run dev
```

### 3. Open in Browser
Visit:
```
http://localhost:3000
```

## 🎮 Presentation Controls & Navigation

| Control / Key | Action |
|:---|:---|
| **Right Arrow (`→`)** / **Spacebar** / **Page Down** | Advance to Next Slide |
| **Left Arrow (`←`)** / **Page Up** | Go to Previous Slide |
| **Home** | Jump to First Slide (Slide 1: Hero) |
| **End** | Jump to Final Slide (Slide 16: Conclusion) |
| **`N` Key** | Toggle Presenter Defense Notes Modal (Viva Q&A Tips & Talking Points) |
| **`F` / Fullscreen Button** | Toggle Immersive Fullscreen 16:9 Presentation Mode |
| **Autoplay Button** | Enable 7-second automatic slide progression |
| **Progress Bar Segments** | Click any of the 16 dots/segments to instantly jump to that slide |
| **Top Dropdown Menu** | Jump to any of the 16 slides grouped by technical topic |
